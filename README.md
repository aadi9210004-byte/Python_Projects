This repository contains four beginner-friendly Python projects developed using Object-Oriented Programming (OOP). These projects demonstrate practical applications of Python classes, objects, inheritance, encapsulation, abstraction, exception handling, and file handling.

The projects use CSV and TXT files to store records and maintain data between program executions.

Project 01 — Student Management System

Description:
A menu-driven application for managing student information and academic records.

Features:

Add new students.

Display all student records.

Search students using their student ID.

Update existing student records.

Delete student records.

Calculate individual and overall average marks.

Save records in CSV and TXT files.

Load previously saved records automatically from CSV.

Technologies and concepts:

Python classes and objects

Encapsulation and inheritance

Abstract classes and properties

Lists and loops

CSV and TXT file handling

Exception handling

Data files: students.csv, students.txt
